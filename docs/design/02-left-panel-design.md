# 左侧面板设计

状态：Draft  
日期：2026-09-07  
范围：Ergatai 多 Agent 协作平台 - 左侧导航面板

## 1. 设计目标

左侧面板是 Ergatai 的主导航入口，负责：

- **模式切换**：在群聊模式和 Agent 模式之间切换
- **视图切换**：快速切换到任务看板、DAG 可视化等视图
- **会话管理**：创建、选择、管理群聊和私聊会话
- **快速导航**：通过列表快速定位到目标会话
- **上下文感知**：根据当前模式显示不同的列表内容

## 2. 核心概念

### 2.1 三种视图

主区域支持三种视图模式，通过左侧面板快速切换：

#### 对话视图（Conversation View）

**场景**：默认的对话交互界面

- 群聊模式：显示项目群的多 Agent 对话
- Agent 模式：显示与单个 Agent 的私聊对话
- 支持活动卡、审批卡、消息等

#### 任务看板视图（Task Kanban View）

**场景**：任务管理和追踪

- 四列看板：尚未开始、正在进行中、成功、失败
- 任务卡片形式，参考群聊活动卡设计
- 点击卡片展开详情，显示工具调用等

#### DAG 可视化视图（DAG Visualization View）

**场景**：任务依赖关系可视化

- 展示 DAG 图结构
- 实时显示节点状态和进度
- 支持缩放、拖拽、导出

### 2.2 两种模式

Ergatai 提供两种交互模式，对应不同的协作范式：

#### 群聊模式（Group Chat Mode）

**场景**：多 Agent 协作，类似项目群聊

- 用户可以创建项目群，邀请多个 Agent 加入
- 通过 `@Agent` 触发任务
- 群内支持任务卡、审批卡、结果卡
- 适合需要多个 Agent 协同完成的复杂任务

**数据模型**：
- `Conversation`（群聊）：包含多个成员（用户 + Agent）
- `GroupMessage`：群聊消息
- `ActivityCard`：活动卡，绑定异步 Run

#### Agent 模式（Agent Mode）

**场景**：单个 Agent 对话，类似 IM 私聊

- 用户与单个 Agent 一对一对话
- Agent 可以内部启动子 Agent 完成任务
- 适合简单任务或需要深度对话的场景

**数据模型**：
- `Session`（会话）：用户与单个 Agent 的对话
- `Message`：对话消息
- `SubAgent`：主 Agent 启动的子 Agent

### 2.2 列表层级

```
左侧面板
├── 任务列表（持久化，类似会话列表）
│   └── 显示所有任务（按活跃度排序）
│       └── 点击任务 → 主区域显示任务详情或看板
│
├── 群聊列表（群聊模式）
│   └── 显示所有项目群
│       └── 点击群聊 → 主区域显示该群的对话
│
└── 会话列表（Agent 模式）
    └── 显示所有私聊会话
        └── 点击会话 → 主区域显示该会话的对话
```

**任务列表**：
- 持久化保存，不会自动消失
- 按活跃度排序：运行中/等待中置顶，已完成/失败自动下移
- 每个任务显示：标题、状态图标、时间
- 不显示 Agent 信息（在任务详情中查看）
- 支持搜索和筛选

**群聊列表**：
- 展示用户加入的所有项目群
- 每个群聊包含：群名称、成员头像、最新消息预览、未读数
- 支持搜索和过滤

**会话列表**：
- 展示用户的所有私聊会话
- 每个会话包含：Agent 名称、头像、最新消息预览、未读数
- 支持搜索和过滤

### 3.2 组件说明

#### 搜索框

**位置**：顶部  
**功能**：
- 搜索群聊、会话、消息内容
- 支持模糊匹配和标签过滤
- 快捷键：`Ctrl/Cmd + K`

**交互**：
- 输入时实时过滤下方列表
- 支持搜索语法：`type:group`, `agent:claude`, `has:mention`

#### 模式切换 tabs

**位置**：搜索框下方  
**功能**：
- 切换群聊模式和 Agent 模式
- 平铺显示，不使用下拉器

**交互**：
- 点击 tab 切换模式
- 切换后下方列表内容随之变化
- 选中状态有明显视觉反馈

#### 新建按钮

**位置**：模式 tabs 下方  
**功能**：
- 创建新的群聊或私聊会话
- 点击后弹出创建对话框

**交互**：
- 群聊模式：弹出"创建项目群"对话框，选择 Agent 成员
- Agent 模式：弹出"新建私聊"对话框，选择 Agent

#### 任务入口

**位置**：新建按钮下方，群聊列表上方  
**功能**：
- 显示所有任务（持久化，类似会话列表）
- 任务按活跃度排序：运行中/等待中置顶，已完成/失败自动下移
- 点击后主区域切换到任务详情

**任务列表项内容**：
- 任务标题
- 状态图标（颜色区分：运行中-蓝色，等待中-黄色，已完成-绿色，失败-红色）
- 时间（最后活动时间）
- **不显示 Agent 信息**（Agent 信息在任务详情中查看）

**排序规则**：
1. 运行中/等待中的任务置顶
2. 按最后活动时间排序（最新的在上）
3. 已完成/失败的任务自动下移
4. 支持搜索和筛选

**交互**：
- 点击任务 → 主区域显示任务详情
- 右键菜单：查看详情、删除、归档
- 支持搜索任务
- 任务持久化保存，不会自动消失

#### 群聊列表

**位置**：新建按钮下方  
**功能**：
- 展示用户加入的所有项目群
- 默认展开，可折叠

**列表项内容**：
- 群名称
- 成员头像（最多显示 3 个）
- 成员数量
- 最新消息时间或预览
- 未读消息数（红点或数字）
- 选中状态（高亮背景）

**交互**：
- 点击列表项 → 中间面板切换到该群聊
- 右键菜单：置顶、静音、退出群聊、查看详情
- 拖拽排序（可选）

#### 会话列表

**位置**：群聊列表下方  
**功能**：
- 展示用户的所有私聊会话
- 默认展开，可折叠

**列表项内容**：
- Agent 名称
- Agent 头像
- Agent 类型（Claude/Codex/GPT-4 等）
- 最新消息时间或预览
- 未读消息数
- 选中状态

**交互**：
- 点击列表项 → 中间面板切换到该会话
- 右键菜单：置顶、删除、查看详情
- 拖拽排序（可选）

#### 设置入口

**位置**：底部  
**功能**：
- 打开设置面板
- 显示用户信息

**交互**：
- 点击打开设置对话框或跳转到设置页面

## 4. 状态管理

### 4.1 全局状态

```typescript
interface LeftPanelState {
  // 当前模式
  mode: 'group_chat' | 'agent';
  
  // 搜索关键词
  searchQuery: string;
  
  // 当前选中的会话 ID
  activeConversationId: string | null;
  activeSessionId: string | null;
  
  // 列表折叠状态
  groupListCollapsed: boolean;
  sessionListCollapsed: boolean;
  
  // 列表数据
  conversations: Conversation[];
  sessions: Session[];
}
```

### 4.2 数据流

```
用户操作
  ↓
更新 LeftPanelState
  ↓
触发中间面板切换
  ↓
加载对应会话/群聊的消息
  ↓
渲染中间面板
```

## 5. 交互细节

### 5.1 模式切换

**场景**：用户从群聊模式切换到 Agent 模式

**行为**：
1. 用户点击"Agent 模式" tab
2. 下方列表内容切换为会话列表
3. 如果之前选中的是群聊，切换到 Agent 模式后自动选中第一个会话
4. 中间面板切换到对应的私聊对话

### 5.2 新建会话

**场景**：用户在群聊模式点击"新建会话"

**行为**：
1. 弹出"创建项目群"对话框
2. 用户输入群名称
3. 用户选择要邀请的 Agent（可多选）
4. 用户设置群聊选项（如未 mention 策略）
5. 点击"创建"
6. 新群聊出现在群聊列表顶部
7. 自动选中新群聊，中间面板切换到该群聊

### 5.3 列表项右键菜单

**群聊列表项右键菜单**：

```
┌────────────────────────┐
│ 📌 置顶                 │
│ 🔕 静音                 │
│ 📋 复制群 ID            │
│ ⚙️ 群设置               │
│ 🚪 退出群聊             │
└────────────────────────┘
```

**会话列表项右键菜单**：

```
┌────────────────────────┐
│ 📌 置顶                 │
│ 🗑️  删除会话             │
│ 📋 复制会话 ID          │
└────────────────────────┘
```

## 6. 响应式设计

### 6.1 桌面端（> 1024px）

- 左侧面板固定宽度：280px
- 所有列表项完整显示
- 支持列表项 hover 效果

### 6.2 平板端（768px - 1024px）

- 左侧面板可折叠
- 折叠后只显示图标（模式、新建、设置）
- 展开后显示完整列表

### 6.3 移动端（< 768px）

- 左侧面板默认隐藏
- 通过顶部导航栏的菜单按钮打开
- 打开后覆盖中间面板
- 选中会话后自动关闭

## 7. 性能优化

### 7.1 列表虚拟化

- 群聊和会话列表使用虚拟滚动
- 只渲染可见区域的列表项
- 支持大量会话（1000+）不卡顿

### 7.2 数据缓存

- 列表数据缓存在内存中
- 未读数通过 WebSocket 实时更新
- 消息预览缓存最近一条

### 7.3 懒加载

- 首次加载只显示列表
- 点击列表项时再加载完整消息历史
- 消息分页加载（每次 50 条）

## 8. 无障碍设计

### 8.1 键盘导航

- `Tab`：在组件间切换焦点
- `↑/↓`：在列表项间移动
- `Enter`：选中列表项
- `Space`：折叠/展开列表
- `Ctrl/Cmd + K`：聚焦搜索框

### 8.2 屏幕阅读器

- 所有交互元素有清晰的 aria-label
- 列表项有 role="listitem"
- 模式 tabs 有 role="tab" 和 aria-selected
- 未读数有 aria-label="X 条未读消息"

### 9.2 状态管理

推荐使用 Zustand 或 Redux Toolkit：

```typescript
// store/leftPanel.ts
const useLeftPanelStore = create((set) => ({
  mode: 'group_chat',
  searchQuery: '',
  activeConversationId: null,
  activeSessionId: null,
  
  setMode: (mode) => set({ mode }),
  setSearchQuery: (query) => set({ searchQuery: query }),
  setActiveConversation: (id) => set({ activeConversationId: id }),
  setActiveSession: (id) => set({ activeSessionId: id }),
}));
```

### 9.3 样式方案

推荐使用 Tailwind CSS 或 styled-components：

```typescript
// 示例：模式 tabs
<div className="flex gap-2 p-2 border-b">
  <button
    className={`flex-1 py-2 px-4 rounded ${
      mode === 'group_chat'
        ? 'bg-blue-500 text-white'

    onClick={() => setMode('group_chat')}

    Agent 模式
  </button>

```

## 10. 开放问题

1. **列表排序**：是否支持自定义排序（按时间、按名称、手动拖拽）？
2. **分组显示**：群聊列表是否需要按项目或标签分组？
3. **快速切换**：是否需要快捷键在不同会话间快速切换（如 `Ctrl+1`, `Ctrl+2`）？
4. **离线状态**：离线时列表如何显示？是否显示缓存数据？
5. **多设备同步**：未读数是否需要在多设备间同步？

## 11. 成功指标

- 用户能在 1 秒内找到并切换到目标会话
- 列表滚动流畅，无卡顿（60fps）
- 模式切换响应时间 < 100ms
- 新建会话流程 < 10 秒完成
- 搜索响应时间 < 200ms
