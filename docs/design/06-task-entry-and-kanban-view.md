# 任务入口与看板视图设计

状态：Draft  
日期：2026-09-07  
范围：Ergatai 多 Agent 协作平台 - 任务入口位置与看板视图  
补充文档：05-task-panel-and-dag-visualization.md

## 1. 设计目标

明确任务面板的入口位置和主区域展示方式：

- **左侧入口**：在左侧面板添加任务入口，显示运行中的任务摘要
- **主区域展示**：点击任务入口后，主区域切换为四列看板视图
- **卡片式设计**：任务以卡片形式展示，参考群聊活动卡设计
- **详情展开**：点击卡片展开任务详情，显示工具调用等信息

## 2. 左侧面板任务入口

### 2.1 入口位置

在左侧面板的模式切换下方、群聊列表上方添加任务列表区域：

```
+-------------------------+
| 搜索...                  |
+-------------------------+
| [群聊模式] [Agent模式]   |
+-------------------------+
| [+ 新建会话]             |
+-------------------------+
| ▼ 任务                   |  ← 任务列表（持久化）
| ├─ 🔵 修复登录超时       |  ← 运行中（置顶）
| │  刚刚                  |
| ├─ 🟡 审查代码           |  ← 等待中（置顶）
| │  5 分钟前              |
| ├─ 🟢 分析问题           |  ← 已完成（下移）
| │  1 小时前              |
| ├─ 🟢 重构模块           |  ← 已完成
| │  2 小时前              |
| ├─ 🔴 更新文档           |  ← 失败（保留）
| │  昨天                  |
| └─ ...                   |
+-------------------------+
| 群聊列表                 |
| ...                      |
+-------------------------+
| 会话列表                 |
| ...                      |
+-------------------------+
| 设置                     |
+-------------------------+
```

### 2.2 列表内容

**任务列表项**：
- **任务标题**：任务名称
- **状态图标**：颜色区分（运行中-蓝色，等待中-黄色，已完成-绿色，失败-红色）
- **时间**：最后活动时间
- **不显示 Agent 信息**：Agent 信息在任务详情中查看

**排序规则**：
1. 运行中/等待中的任务置顶
2. 按最后活动时间排序（最新的在上）
3. 已完成/失败的任务自动下移
4. 支持搜索和筛选

**持久化策略**：
- 任务持久化保存，不会自动消失
- 类似会话列表，旧任务自动下移
- 支持搜索历史任务

### 2.3 交互

**点击行为**：
- 点击任务 → 主区域显示任务详情
- 可以在详情中切换到看板视图或 DAG 视图

**右键菜单**：
- 查看详情
- 查看看板视图
- 查看 DAG 视图
- 删除
- 归档

**搜索**：
- 支持搜索任务标题
- 支持按状态筛选
- 支持按时间范围筛选

## 3. 主区域任务看板

### 3.1 看板布局

点击左侧任务入口后，主区域切换为四列看板视图：

```
+--------------------------------------------------------------------------+
| 任务看板                                              [返回列表] [DAG视图] |
+--------------------------------------------------------------------------+
|                                                                          |
| 尚未开始 (2)          正在进行中 (1)          成功 (3)          失败 (0)   |
| +-----------------+  +-----------------+  +-----------------+  +-------+ |
| | 更新文档         |  | 修复登录超时     |  | 分析问题         |  |       | |
| | GPT-4 | 低优先级 |  | Codex | 高优先级 |  | Codex | 完成     |  |       | |
| |                 |  |                 |  |                 |  |       | |
| | 等待前置任务完成 |  | 进度: 60%       |  | 耗时: 5 分钟     |  |       | |
| | 依赖: #1        |  | 正在: 等待审批   |  | 产出: 1 个文件   |  |       | |
| +-----------------+  +-----------------+  +-----------------+  +-------+ |
|                                                                          |
| +-----------------+  +-----------------+  +-----------------+            |
| | 优化性能         |  | 审查代码变更     |  | 重构认证模块     |            |
| | Codex | 中优先级 |  | Claude | 等待中  |  | Codex | 完成     |            |
| |                 |  |                 |  |                 |            |
```

### 3.2 四列定义

| 列名 | 包含状态 | 颜色主题 | 说明 |
|-----|---------|---------|------|
| 尚未开始 | pending, queued | 灰色 | 待执行的任务 |
| 正在进行中 | running, waiting | 蓝色 | 执行中或等待审批/依赖的任务 |
| 成功 | completed | 绿色 | 已完成的任务 |
| 失败 | failed, cancelled | 红色 | 失败或取消的任务 |

### 3.3 列头信息

每列顶部显示：
- 列名
- 任务数量（括号内）
- 筛选按钮（可选）

### 3.4 任务卡片设计

任务卡片参考群聊活动卡设计，分为收起和展开两种状态：

#### 收起状态（默认）

```
+-----------------------------------+
| 修复登录超时                [高]   |  ← 标题 + 优先级标签
| Codex | 运行中                    |  ← Agent + 状态
+-----------------------------------+
| 正在定位 refresh token 竞态条件   |  ← 当前状态摘要
| 已读取 6 个文件                    |  ← 进度信息
|                                    |
| 进度: ████████░░ 60%              |  ← 进度条
| 耗时: 8 分钟                       |  ← 时间信息
+-----------------------------------+
| [查看详情] [暂停] [停止]          |  ← 操作按钮（悬停显示）
+-----------------------------------+
```

**卡片内容**：
- **标题**：任务名称
- **优先级标签**：高/中/低，用颜色区分
- **Agent 信息**：执行任务的 Agent 名称和类型
- **状态**：当前状态（运行中、等待中等）
- **状态摘要**：当前正在做什么（来自 Run Events）
- **进度信息**：工具调用摘要、文件读取数量等
- **进度条**：可视化进度（0-100%）
- **时间信息**：已耗时或预计时间
- **操作按钮**：查看详情、暂停、停止（悬停时显示）

#### 展开状态（点击卡片）

```
+-----------------------------------+
| 修复登录超时                [高]   |
| Codex | 运行中                    |
+-----------------------------------+
| 描述：                              |
| 修复 refresh token 竞态条件问题   |
+-----------------------------------+
| 执行过程：                          |
| +-------------------------------+ |
| | 14:32 开始分析问题            | |
| | 14:35 读取 auth/session.ts    | |
| | 14:38 读取 auth/token.ts      | |
| | 14:40 定位到 refresh token    | |
| | 14:42 准备修复方案            | |
| | 14:45 等待审批（当前）        | |
| +-------------------------------+ |
+-----------------------------------+
| 工具调用：                          |
| ├─ read_file(auth/session.ts) ✓   |
| ├─ read_file(auth/token.ts) ✓     |
| └─ search_code("refresh") ✓       |
+-----------------------------------+
| 产出物：                            |
| └─ auth-fix.patch (待生成)        |
+-----------------------------------+
| [暂停] [取消] [查看日志] [查看文件] |
+-----------------------------------+
```

**展开内容**：
- 任务描述
- 执行过程时间线（参考群聊活动卡的展开状态）
- 工具调用历史
- 产出物列表
- 完整操作按钮

### 3.5 卡片交互

**点击行为**：
- 单击卡片 → 展开/收起卡片
- 双击卡片 → 打开任务详情面板（侧边栏）

**悬停行为**：
- 悬停显示操作按钮（查看详情、暂停、停止）
- 显示更多任务信息（如依赖关系）

**拖拽行为**（可选）：
- 支持拖拽卡片在列间移动
- 移动时自动更新任务状态
- 需要确认对话框（防止误操作）

**右键菜单**：
- 查看详情
- 查看日志
- 查看文件变更
- 暂停/恢复
- 取消任务
- 复制任务 ID

### 4.2 详情内容

**基本信息**：
- 任务标题
- 状态和进度
- Agent 信息
- 创建时间、开始时间、预计耗时
- 优先级

**描述**：
- 任务描述文本

**执行过程**：
- 时间线形式展示执行步骤
- 每个步骤包含：时间、动作、状态
- 实时更新（通过 SSE/WebSocket）

**工具调用**：
- 列表形式展示所有工具调用
- 每个调用包含：工具名、参数、状态、耗时
- 可展开查看详细输入输出

**产出物**：
- 列表形式展示所有产出物
- 包含：文件名、类型、大小、下载链接
- 可点击预览或下载

**依赖关系**：
- 显示当前任务依赖的其他任务
- 显示依赖当前任务的其他任务
- 点击可跳转到相关任务

**操作按钮**：
- 暂停/恢复
- 取消
- 重试（失败时）
- 查看日志
- 查看文件变更
- 查看详情（打开全屏详情）

## 5. 状态管理

### 5.1 左侧任务入口状态

```typescript
interface TaskEntryState {
  // 运行中的任务列表

  // 是否展开

  taskCounts: {

    completed: number;
    failed: number;
  };
}
```

### 5.2 看板视图状态

```typescript
interface KanbanViewState {
  // 当前视图模式
```

### 5.3 实时更新

```typescript
// 订阅任务更新
useEffect(() => {
  const unsubscribe = taskEventBus.subscribe('task_updated', (task) => {
    // 更新看板视图
    updateKanbanView(task);
    
    // 更新左侧入口
    updateTaskEntry(task);
  });

  return unsubscribe;
}, []);

// 订阅任务创建
useEffect(() => {
  const unsubscribe = taskEventBus.subscribe('task_created', (task) => {
    // 添加到看板
    addTaskToKanban(task);
    
    // 更新左侧入口计数
    incrementTaskCount(task.status);
  });

  return unsubscribe;
}, []);
```

## 8. 实现建议

### 8.1 看板库选择

推荐使用 **react-beautiful-dnd** 或 **@hello-pangea/dnd**：

```typescript
import { DragDropContext, Droppable, Draggable } from '@hello-pangea/dnd';

function KanbanBoard() {
  return (
    <DragDropContext onDragEnd={handleDragEnd}>
      <div className="kanban-board">
        {columns.map((column) => (
          <Droppable key={column.id} droppableId={column.id}>
            {(provided) => (
              <div ref={provided.innerRef} {...provided.droppableProps}>
                <ColumnHeader title={column.title} count={column.tasks.length} />
                <TaskCardList tasks={column.tasks} />
                {provided.placeholder}
              </div>
            )}
          </Droppable>
        ))}
      </div>
    </DragDropContext>
  );
}
```

### 8.2 卡片动画

使用 Framer Motion 实现卡片展开/收起动画：

```typescript
import { motion, AnimatePresence } from 'framer-motion';

function TaskCard({ task }) {
  const [expanded, setExpanded] = useState(false);

  return (
    <motion.div
      layout
      className="task-card"
      onClick={() => setExpanded(!expanded)}
    >
      <TaskCardHeader task={task} />
      <AnimatePresence>
        {expanded && (
          <motion.div
            initial={{ height: 0, opacity: 0 }}
            animate={{ height: 'auto', opacity: 1 }}
            exit={{ height: 0, opacity: 0 }}
          >
            <TaskCardBody task={task} />
          </motion.div>
        )}
      </AnimatePresence>
      <TaskCardFooter task={task} />
    </motion.div>
  );
}
```

## 9. 与群聊活动卡的关系

### 9.1 设计一致性

任务看板卡片与群聊活动卡保持一致的设计语言：
- 相同的卡片结构（标题、状态、进度、操作）
- 相同的时间线展示方式
- 相同的工具调用展示方式
- 相同的操作按钮样式

### 9.2 数据共享

任务看板卡片和群聊活动卡共享同一数据源：
- 都从 Task API 获取数据
- 都订阅相同的 Run Events
- 都使用相同的更新机制

### 9.3 交互联动

- 群聊中点击活动卡的"详情" → 打开任务看板并展开该任务
- 任务看板中点击"查看群聊" → 跳转到对应的群聊消息

## 11. 成功指标

- 任务入口加载时间 < 200ms
- 看板视图渲染时间 < 500ms（50 个任务以内）
- 卡片展开/收起动画流畅（60fps）
- 任务状态更新延迟 < 200ms
- 用户能在 2 秒内找到目标任务
