# 右侧面板设计

状态：Draft  
日期：2026-09-07  
范围：Ergatai 多 Agent 协作平台 - 右侧工具面板

## 1. 设计目标

右侧面板是 Ergatai 的工具和上下文展示区域，负责：

- **多标签页管理**：通过浏览器标签页形式展示多个工具面板
- **灵活扩展**：支持动态添加新的面板标签
- **上下文展示**：展示对话、终端、文件、代码审查等辅助信息
- **复用现有组件**：基于前端已有的 5 个面板组件构建

## 2. 核心概念

### 2.1 标签页系统

右侧面板采用**浏览器标签页**模式：

- 每个标签页是一个独立的工具面板
- 可以同时打开多个标签页
- 标签页可以关闭、拖拽排序、固定
- 支持"+ 新建"按钮添加新标签页

### 2.2 五种面板类型

系统基于前端已有的 5 个面板组件：

#### 1. ChatPanel（聊天面板）

**用途**：与 Agent 的对话界面

- 展示与单个 Agent 或群聊的对话历史
- 支持消息输入、@mention、文件发送
- 实时显示 Agent 回复和执行状态
- 支持活动卡、审批卡等富文本消息

**场景示例**：
- 群聊模式：展示多 Agent 协作的群聊对话
- Agent 模式：展示与单个 Agent 的私聊对话
- 侧边对话：与特定 Agent 的独立对话窗口

#### 2. TerminalPanel（终端面板）

**用途**：Agent 执行终端和命令输出

- 基于 xterm.js 的完整终端模拟器
- 支持多会话管理
- 实时显示 Agent 的命令执行输出
- 支持交互式命令输入

**场景示例**：
- 查看 Agent 执行的 shell 命令
- 查看构建、测试输出
- 调试和排查问题

#### 3. FilesPanel（文件面板）

**用途**：代码编辑器和文件查看器

- 基于 Monaco Editor 的代码编辑器
- 支持语法高亮（TypeScript、JavaScript、JSON、YAML 等）
- 支持文件编辑和保存
- 支持只读模式查看文件

**场景示例**：
- 查看 Agent 修改的代码文件
- 编辑配置文件
- 查看日志文件

#### 4. ReviewPanel（审查面板）

**用途**：代码变更审查

- 展示 Git diff 视图
- 支持并排和统一视图切换
- 支持审查决策（批准/拒绝/需要修改）
- 支持文件级和行级评论

**场景示例**：
- 审查 Agent 的代码修改
- 查看文件变更历史
- 做出审查决策

#### 5. PlaceholderPanel（占位面板）

**用途**：预留面板位置

- 显示"即将推出"提示
- 用于未来扩展新功能
- 保持界面完整性

**场景示例**：
- 未来可能添加的任务详情面板
- 未来可能添加的产出物面板
- 临时占位，等待功能开发

## 3. 面板结构

### 3.1 布局

```
+--------------------------------------+
| [聊天] [终端] [文件] [审查] [+]      |  <- 标签栏
+--------------------------------------+
|                                      |
|                                      |
|         当前标签页内容                 |
|                                      |
|                                      |
|                                      |
+--------------------------------------+
```

### 3.2 标签栏

**位置**：顶部  
**功能**：
- 显示已打开的标签页
- 支持切换、关闭、拖拽排序
- "+ 新建"按钮添加新标签页

**标签项内容**：
- 图标（标识面板类型）
- 标题（面板名称或上下文名称）
- 关闭按钮（x）
- 未读标记（可选）

**交互**：
- 点击标签 -> 切换到该面板
- 中键点击或点击 x -> 关闭标签
- 拖拽标签 -> 重新排序
- 右键菜单 -> 关闭其他、关闭右侧、固定标签

### 3.3 "+ 新建"按钮

**位置**：标签栏右侧  
**功能**：
- 点击弹出面板选择菜单
- 选择面板类型后创建新标签页

**菜单内容**：

```
+------------------------+
| 聊天面板                |
| 终端面板                |
| 文件面板                |
| 审查面板                |
+------------------------+
```

**交互**：
- 点击菜单项 -> 创建对应类型的新标签页
- 新标签页自动激活并显示
- 部分面板可能需要额外选择上下文（如选择 Agent、文件路径）

## 4. 各面板详细设计

### 4.1 ChatPanel（聊天面板）

+--------------------------------------+

+--------------------------------------+

#### 功能

- **对话历史**：展示与特定 Agent 或群组的完整对话

1. 点击"+ 新建" -> "聊天面板"
2. 弹出 Agent 或群聊选择对话框
3. 选择目标 Agent 或群聊
4. 创建新标签页，标题为"与 {AgentName} 的对话"或"{GroupName}"

2. 创建新标签页，标题为"终端"

## 5. 状态管理

### 5.1 全局状态

```typescript
interface RightPanelState {
  // 打开的标签页
  tabs: Tab[];
  
  // 当前激活的标签页 ID
  activeTabId: string | null;
  
  // 标签页顺序
  tabOrder: string[];
}

interface Tab {
  id: string;
  type: TabType;
  title: string;
  icon: string;
  data: any; // 标签页特定数据
  closable: boolean;
  pinned: boolean;
  unread?: boolean;
}

type TabType = 
  | 'chat'
  | 'terminal'
  | 'files'
  | 'review';
```

### 5.2 数据流

```
用户点击"+ 新建"
  |
  v
选择面板类型
  |
  v
创建新 Tab 对象
  |
  v
添加到 tabs 数组
  |
  v
设置为 activeTabId
  |
  v
渲染对应面板组件
```

## 6. 交互细节

### 6.1 标签页操作

#### 打开标签页

**场景**：用户点击"+ 新建"按钮

**行为**：
1. 弹出面板选择菜单
2. 用户选择面板类型
3. 如果需要选择上下文（如 Agent、文件），弹出选择对话框
4. 创建新标签页并添加到标签栏
5. 自动激活新标签页

#### 关闭标签页

**场景**：用户点击标签页的关闭按钮

**行为**：
1. 如果标签页有未保存的内容（如文件编辑器），弹出确认对话框
2. 从 tabs 数组中移除该标签页
3. 如果关闭的是当前激活的标签页，激活右侧的标签页
4. 如果没有标签页了，显示空状态

#### 切换标签页

**场景**：用户点击标签栏中的标签

**行为**：
1. 将 activeTabId 设置为该标签的 ID
2. 中间区域渲染对应的面板内容
3. 清除该标签的未读标记

#### 拖拽排序

**场景**：用户拖拽标签

**行为**：
1. 拖拽时显示占位符
2. 释放时更新 tabOrder 数组
3. 持久化标签顺序

### 6.2 右键菜单

**标签栏右键菜单**：

```
+------------------------+
| 重新加载                |
| 固定标签                |
| 关闭标签                |
| 关闭其他标签            |
| 关闭右侧标签            |
+------------------------+
```

### 6.3 快捷键

- `Ctrl/Cmd + T`：打开新建标签页菜单
- `Ctrl/Cmd + W`：关闭当前标签页
- `Ctrl/Cmd + Tab`：切换到下一个标签页
- `Ctrl/Cmd + Shift + Tab`：切换到上一个标签页
- `Ctrl/Cmd + 1-9`：切换到第 N 个标签页

## 7. 响应式设计

### 7.1 桌面端（> 1024px）

- 右侧面板固定宽度：400px
- 标签栏完整显示所有标签
- 标签过多时显示滚动条

### 7.2 平板端（768px - 1024px）

- 右侧面板可折叠
- 折叠后只显示标签图标
- 展开后显示完整标签和面板

### 7.3 移动端（< 768px）

- 右侧面板默认隐藏
- 通过底部工具栏打开
- 打开后覆盖中间面板
- 一次只能显示一个标签页

## 8. 性能优化

### 8.1 懒加载

- 标签页内容只在激活时加载
- 非激活标签页暂停数据更新
- 大型组件（如 Monaco Editor）使用 lazy loading

### 8.2 状态持久化

- 标签页状态持久化到 localStorage
- 应用重启时恢复打开的标签页
- 支持标签页快照

### 8.3 数据缓存

- 文件内容缓存到内存
- 终端会话保持连接
- 对话历史分页加载

## 9. 无障碍设计

### 9.1 键盘导航

- `Tab`：在标签间切换
- `Arrow Keys`：在标签项间移动
- `Enter`：激活标签
- `Delete`：关闭标签

### 9.2 屏幕阅读器

- 标签栏有 role="tablist"
- 标签项有 role="tab" 和 aria-selected
- 面板内容有 role="tabpanel"
- 未读标记有 aria-label="有未读消息"

### 10.2 状态管理

```typescript
// store/rightPanel.ts
const useRightPanelStore = create((set) => ({
  tabs: [],
  activeTabId: null,
  
  addTab: (tab) => set((state) => ({
    tabs: [...state.tabs, tab],
    activeTabId: tab.id,
  })),
  
  removeTab: (id) => set((state) => {
    const newTabs = state.tabs.filter(t => t.id !== id);
    const newActiveId = state.activeTabId === id
      ? newTabs[newTabs.length - 1]?.id || null
      : state.activeTabId;
    return {
      tabs: newTabs,
      activeTabId: newActiveId,
    };
  }),
  
  setActiveTab: (id) => set({ activeTabId: id }),
}));
```

## 11. 开放问题

1. **标签页数量限制**：是否限制同时打开的标签页数量（如最多 10 个）？
2. **标签页分组**：是否支持将相关标签页分组（如所有文件面板放在一组）？
3. **标签页持久化**：是否需要在多设备间同步打开的标签页？
4. **面板扩展**：是否允许第三方插件注册新的面板类型？
5. **标签页预览**：鼠标悬停在标签上时是否显示内容预览？
6. **PlaceholderPanel 用途**：是否需要保留占位面板，还是移除以简化界面？

## 12. 成功指标

- 用户能在 1 秒内打开新的面板标签
- 标签切换响应时间 < 50ms
- 面板内容加载时间 < 500ms
- 支持同时打开 10+ 标签页不卡顿
- 标签页状态恢复成功率 > 95%
